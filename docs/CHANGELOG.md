# تغییرات

## Phase 13A — قفل برنامه با PIN
- افزودن قفل چهاررقمی با ذخیره‌سازی hash و salt، محدودیت موقت پس از پنج تلاش ناموفق و قفل هنگام شروع/بازگشت پس از مهلت.
- افزودن تنظیمات فعال‌سازی، تغییر و غیرفعال‌سازی PIN و گزینه مخفی‌کردن پیش‌نمایش در برنامه‌های اخیر.
- قفل‌شدن رابط اصلی تا زمان احراز هویت؛ اطلاعات PIN وارد بکاپ نمی‌شوند.
